Demande : analyser galerie/favoris/panier pour invité et compte, corriger les
anomalies confirmées, réduire les polices centrales, animer chaque chiffre et

## Diagnostic

- Les captures montrent des favoris (cœur), distincts des ajouts panier (+).
  Deux des pièces aimées sont vendues. Leur absence du panier est normale.
- Le panneau ignorait l'import invité lors d'une connexion : il lisait seulement
  le panier UID, alors que l'import était limité à la page checkout.
- Le panneau et le checkout invités ignoraient les changements d'autres onglets.
- L'espacement négatif du montant, combiné aux masques individuels, rognait les
  caractères. Les séparateurs étaient aussi animés comme des chiffres.

- Écoute des changements de stockage invité dans les deux vues.
- Typographie centrale réduite, masques avec marge latérale, rouleaux de quatre
  positions par chiffre, décalage de 55 ms ; ponctuation fixe, mouvement réduit.
- 19 tests ciblés réussis sous Node 22.23.2 : panier, transmission des clics,
  favoris, migrations concurrentes/échouées et cache de livraison.
- Quatre scénarios UI Chromium isolés réussis : total/suppression/erreur,
  clavier et focus, largeurs 320–1920, sombre et mouvement réduit. Capture
  claire relue. Les tests n'utilisent ni compte réel ni paiement Stripe.
- Lint ciblé et `git diff --check` réussis. Build Next sous Node 22.23.2
